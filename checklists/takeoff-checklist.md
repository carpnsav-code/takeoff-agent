# Master Takeoff Checklist — Polished Concrete & Epoxy

Run this before any takeoff goes out. Every unchecked box is either resolved, RFI'd, or excluded in writing.

## Documents
- [ ] Full spec sections received: 03 35 43 and/or 09 67 23 (+ variants)
- [ ] Finish plans + finish schedule/legend received and reconciled against each other
- [ ] All addenda incorporated (list addendum numbers on the takeoff)
- [ ] Structural sheets checked for joint layout, slab thickness, vapor retarder
- [ ] Plumbing plans checked for drains/penetrations
- [ ] Bid form checked for required alternates, unit prices, breakdowns

## System identification
- [ ] Each finish code mapped to a spec'd system
- [ ] Polish: exposure class + gloss level stated per area
- [ ] Epoxy: full layer build + total mils stated per system
- [ ] Colors/patterns/dye counted; demarcation striping LF counted
- [ ] Basis-of-design manufacturer + "or equal" status noted
- [ ] Warranty term and applicator qualifications noted (can we meet them?)

## Quantities
- [ ] SF by system, by area, by phase, new vs existing — with sheet references
- [ ] Surface prep SF as separate line(s), method matched to required CSP
- [ ] Existing coating/mastic/curing compound removal SF (if any)
- [ ] Cove base LF × height + corners EA
- [ ] Joint fill/treatment LF + whose scope confirmed
- [ ] Edge/hand work LF (polish) or termination/keyway LF (epoxy)
- [ ] Crack repair LF or allowance
- [ ] Drains, penetrations, columns EA
- [ ] Mock-ups EA + size
- [ ] Moisture tests EA (F2170: 3 + 1 per 1000 SF)
- [ ] Mobilizations/phases counted; night/weekend work flagged
- [ ] Protection SF (during work + finished-floor protection if ours)
- [ ] Material sanity check: gallons/kits/aggregate vs SF math

## Risk items
- [ ] Moisture: spec limits recorded; mitigation included / excluded / unit-priced — stated which
- [ ] Slab cure time vs schedule checked
- [ ] Slab flatness/cure method/mix reviewed for polish impact
- [ ] Slopes-to-drain vs SL system compatibility checked
- [ ] Power, water, slurry disposal, temporary heat addressed
- [ ] Occupied-building constraints (odor, hours, containment) addressed
- [ ] Abatement / hazardous materials explicitly excluded

## Deliverables
- [ ] Quantity sheet complete with sources and assumptions
- [ ] Scope letter: inclusions, exclusions, clarifications, qualifications
- [ ] RFI list numbered and submitted before bid date
- [ ] Reconciliation: total flooring SF vs building area sanity check
