# Uploads

Drop bid documents here, one subfolder per project:

```
uploads/
  2026-example-project/
    specs/          # project manual, spec sections, addenda
    drawings/       # floor plans, finish schedules, details, structural, plumbing
    other/          # RFI responses, site photos, geotech, schedule
```

Useful for a complete takeoff: spec sections 03 35 43 / 09 67 23, finish plans + finish
schedule/legend, dimensioned floor plans, interior elevations/details (cove base!), structural
joint layout, plumbing plans (drains), all addenda, and the bid form.
